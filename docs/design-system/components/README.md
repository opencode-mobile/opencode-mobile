# Component reference

These pages capture shared intent for existing reusable iOS and Android UI.
They are background references. Native public interfaces, previews, galleries,
and tests own implemented behavior.

Do not create or update component pages as part of implementation unless the
user explicitly requests documentation. A component does not require a
Markdown contract or documentation completion ledger before code can change.

Keep public native interfaces variant-first and state-aware. Do not expose raw
colors, one-off typography, arbitrary gradients, or radius overrides as public
customization.
