# Issue tracker: Linear

Issues and PRDs for this repository live in Linear.

| Item | Value |
| --- | --- |
| Team | `Opencode-mobile` (key `OPE`) |
| Project | `opencode apps` |
| Project URL | <https://linear.app/opencode-mobile/project/opencode-apps-f7d80fb00b5a> |

**Linear owns ticket information.** Refine the issue in Linear. Do not
mirror ticket checklists into `docs/features/`.

Repo `plan.md` is the durable product contract only. Update it when shipped
behavior or remaining *product* work changes.

Use the Linear connector to read and mutate issues. Use `gh` for GitHub
PRs, checks, and Actions. GitHub Issues are not the tracker.

Branch names: `feature/ope-<number>-…` or `fix/ope-<number>-…` per
`AGENTS.md`. Ignore Linear’s `{username}/…` suggestion.
