Agreed persistence contract

ConcernConfirmed rule
Preference writesOnly explicit model or variant picks update the New Session Model Preference; accepted sends confirm session state only.
IdentityNormalized server URL + effective username + exact server-provided worktree; passwords excluded.

Boundaries

  • No server API change and no dependency on stale Session.model fields.
  • No mobile pre-creation composer, recent-model UI, visibility controls, or cross-worktree global recency.
  • Agent-configured model precedence waits for mobile agent selection to become server-backed.
