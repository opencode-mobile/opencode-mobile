User goal

Instant home session list and previously opened Session Chat timelines on cold start / slow or unreachable server, then refresh when connectivity returns. Stale read-only browse; block send/mutations while offline.

Caller seam

SessionCache
  seedSessions(worktree) → List<Session>?
  rememberSessions(worktree, sessions)
  openMessages(sessionId, worktree) → Handle { seed / note / flush }
  purgeWorktree / clearAll / estimatedSizeBytes

Internal SessionCacheStore: load / commit / retain / evict / report
  → Room | SwiftData | InMemory

Out of scope

Pagination, SSE patch persistence, LRU, prepared markdown on disk, diffs / permissions / status maps, prefetch of unopened sessions, offline writes, conflating with model-selection SessionModelSelectionStore.

Acceptance gates

  • Cold start with prior cache shows home list before REST completes.
  • Reopen of an opened session shows timeline from disk, then refreshes.
  • Unreachable server: stale browse works; composer cannot send.
  • Settings shows size; Clear Session Cache wipes disk without disconnect.
  • Remove project and Clear All Data purge cache.
  • iOS and Android parity recorded; no Screen Model cache I/O.
