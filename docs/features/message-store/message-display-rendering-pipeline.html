Each kind of state has one clear owner. Renderer-local and viewport changes never feed back into the domain message pipeline.

Coalescible live work

Repository emissions are complete visual snapshots. While projection is busy, an intermediate live snapshot may be replaced by the newest snapshot.

  • Android: one latest live frame plus Flow.conflate().
  • iOS: one latest pending observation update.

Required operations

Explicit load, refresh, and post-send applies cannot be dropped because callers await their state or completion.

  • Android: required FIFO apply queue.
  • iOS: directly awaited MainActor operations.

The timeline converts prepared domain messages into ordered presentation blocks. The view then selects native design-system components without interpreting transport or markdown syntax.

Role rendering

  • User: trailing OpenCodeOutgoingMessage.
  • Assistant: ordered text, attachment, tool-card, and tool-group components.
  • Command/tool/unknown: conservative fallback bubble.
  • Plain bubbles use tap; markdown bubbles use long press so links remain tappable.

Prepared markdown boundary

  • OpenCodeRenderedMarkdown receives an already prepared document.
  • Only http and https links open.
  • Markdown is per text block via BlockDecorationCache (blockID + contentRevision).
  • DisplayMessage.renderedMarkdown is a residual sole-text bridge only; no singleTextBlock paint gate.

Scroll and layout ownership

Auto-follow is a reusable view contract. Pinned geometry only arms or disarms following; while armed, content and viewport changes settle at the exact end.

Shared behavior

  • Initial ready content snaps to the end without animation.
  • A deliberate user scroll away disarms follow.
  • Append, content growth, and viewport shrink anchor the exact end while armed.
  • The scroll-to-end action re-arms follow.
  • Active dragging and deceleration always beat programmatic correction.

Native hosts

  • Android: reverse-layout LazyColumn; bottom anchor at layout index 0.
  • iOS: diffable UICollectionView; last message is the visual bottom item.
  • Hosts apply declared inserted / changed / removed / layoutChanged IDs from TimelineFrame (no live-path layoutSignature or list-wide Equatable).
  • Unarmed: capture/restore visible anchor ID+offset. Armed: settle exact end after layout. Drag: user wins (Android newest-immutable; iOS cell-apply coalesce).
  • Short histories remain bottom-aligned.

Platform walkthroughs

The lanes converge on the same product contract while keeping framework and executor choices native.

Android

StateFlow · worker projection · reverse LazyColumn · Compose

  1. SessionChatScreen Binds session identity and collects state with lifecycle awareness.
  2. SessionChatViewModel Combines region StateFlows into one SessionChatUiState.
  3. SessionChatTimeline Observes display snapshots, reconciles optimism, and projects rows on a worker dispatcher.
  4. SessionChatTimelineView Selects the timeline state and creates the message-list timeline handle.
  5. Reverse LazyColumn Hosts stable message IDs and role/block components.
  6. OpenCodeRenderedMarkdown Materializes prepared blocks and defers large annotation construction.

iOS

Observation · MainActor projection · UICollectionView · SwiftUI/UIKit

  1. SessionChatView Owns the observable model and starts/stops timeline observation with screen lifecycle.
  2. SessionChatViewModel Receives region callbacks and publishes one MainActor UI state.
  3. SessionChatTimeline Can warm-open, coalesces live updates, and cooperatively projects rows.
  4. SessionChatTimelineView Selects the state and owns TimelineScrollController.
  5. MessageListTimelineHost Applies stable-ID diffable snapshots to self-sizing SwiftUI-hosted collection cells.
  6. OpenCodeRenderedMarkdown Materializes prepared blocks and defers large native styling or the first large-tree paint.

Evaluation

What is working well

  • Domain preparation stays outside the UI.
  • The timeline is a focused presentation adapter.
  • The Screen Model exposes one state and explicit actions.
  • Rendering remains component-first and platform-native.
  • Viewport state is isolated from message state.
  • Latest-only coalescing exists only at safe complete-snapshot seams.

Shared invariants

Rows are immutable value snapshots.
Message identity is stable list/cell identity.
Only complete live snapshots may coalesce.
Explicit operation completion is never lost.
Optimistic rows survive quiet live refresh.
Markdown reuse requires matching identity and source.
User scroll intent overrides auto-follow.
Deferred paint never duplicates or reorders rows.
Both platforms preserve block order and actions.
