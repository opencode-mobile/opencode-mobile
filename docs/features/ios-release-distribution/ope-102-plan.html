OPE-102 — iOS Firebase App Distribution On Every Merge

Every successful merge to main produces one signed Ad Hoc IPA and distributes it to the private ios-internal Firebase tester group, without TestFlight or App Store publication. Markdown: ope-102-plan.md.

TriggerEvery push to protected main
ArtifactSigned Ad Hoc IPA
AudiencePrivate ios-internal group
StatusComplete — merge distribute + device install

Delivery flow

1. MergeExact commit lands on main
2. SignArchive + Ad Hoc export via ASC API
3. DistributeFirebase receives the signed IPA
4. InstallOwner installs via tester flow

Checkpoints

CheckpointRequired resultStatus
1 — Human prep ios-internal group; device UDID registered; Firebase SA JSON in ios-release Done
2 — Agent implementation ios-app-distribution.yml, Ad Hoc export, Firebase upload, docs Done (in PR)
3 — Verification Merge-triggered run + physical Ad Hoc install; no store side effects Done
