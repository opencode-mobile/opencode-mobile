OPE-103 — Publish To TestFlight Internal Testing

Extend the signed App Store IPA from OPE-101 so a manual protected iOS Release run uploads to App Store Connect and lands in TestFlight Internal Testing. The app must remain private: not published and not available on the public App Store. Markdown source: ope-103-plan.md.

TriggerManual workflow_dispatch on main
ArtifactSignature-verified App Store IPA
AudienceTestFlight Internal (ASC team users)
PrivacyNot public — no App Review / no store release

Delivery flow

1. DispatchOperator sets version_name on main
2. SignArchive, export, verify IPA (OPE-101)
3. UploadASC accepts the IPA via existing API key
4. InstallHuman waits for processing; TestFlight install
