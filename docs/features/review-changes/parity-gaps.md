by suppressing the pill for the full programmatic scroll animation and aligned
the Changes source-menu checkmark, empty icon spacing, visible labels, and

Changes Refresh button with native pull-to-refresh while preserving the loaded
snapshot during refresh on both platforms. The Changed Files picker also uses
the same semantic addition/deletion subtitle colors and check-only selected
presentation, including selected accessibility meaning, on both platforms.

Navigation Pill contract, filtered stepping, boundary and refresh disabling,
current-file totals, viewport reset, bottom inset, gallery states, and
accessibility meaning on both platforms. The OPE-35 Last turn path,
OPE-36 multi-file navigation, OPE-37 Git Change Sets, OPE-38 Review Changes
