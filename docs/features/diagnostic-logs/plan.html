Diagnostic Logs

GoalShare a redacted 5-minute diagnostic window from Settings without adb/Xcode.
Window5 minutes primary · silent 2,000-entry soft cap.

Architecture

1 Domain / SSE / permission / session emit via app logging facade
2 Dual-write → platform sink + DiagnosticLogBuffer
3 Redact on write · evict by age (5m) then soft entry cap
4 Settings → Developer Tools → Share / Clear

Acceptance gates

  • Export covers last ~5 minutes of always-on areas without secrets or message bodies.
  • Stuck session / pending permission case shows discriminating evidence (SSE, permission refresh, status).
  • Soft-cap truncation, if any, is visible in export metadata.
  • iOS and Android expose the same Settings actions and conceptual fields.
