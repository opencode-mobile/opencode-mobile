Shiki Visual Parity Paths

Top-10 tokenizer gates closed semantic role parity. This plan documents two approaches to close the remaining visual gap vs opencode web.

Two paths

Path A Enriched semantic

Keep CodeTokenRole render tree. Refine scope mapper, add roles sparingly, audit role → design-system token mapping.

  • Low–medium effort
  • More colored tokens, web-like feel
  • No JSON schema change

Path B Scope + Shiki theme

Carry scope stacks in render tree. Bundle live Shiki theme. KMP scope selector → foreground color.

  • High effort
  • Web-exact syntax colors
  • Render-tree version bump
