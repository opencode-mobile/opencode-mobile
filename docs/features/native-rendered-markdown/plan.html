Native Rendered Markdown

Replace the WebView markdown island with shared parsing, native SwiftUI and Compose rendering, and an explicit TextMate highlighter gate.

RuntimeNo WebView

HTML assets, JavaScript bridges, and measured-height callbacks leave the app runtime.

Shared CoreKMP render tree

Android calls the shared parser directly; iOS decodes the versioned JSON render tree from OpenCodeMarkdownCore.

HighlightingTop-10 semantic gate

TextMate/Joni + libonig pass all ten *-basic Shiki semantic oracles. Visual parity and broader language gates remain open.

ChatNative scrolling

Plain text stays plain; markdown-shaped text renders with native layout.
