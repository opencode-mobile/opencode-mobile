Native Rendered Markdown

Replace the WebView markdown island with shared parsing, native SwiftUI and Compose rendering, and an explicit TextMate highlighter gate.

RuntimeNo WebView

HTML assets, JavaScript bridges, and measured-height callbacks leave the app runtime.

Shared CoreKMP render tree

Android consumes the shared parser directly; iOS has the framework build phase and a temporary parser mirror.

HighlightingGate open

Semantic fallback exists, but TextMate/Oniguruma must pass before claiming Shiki-level highlighting.

ChatNative scrolling

Plain text stays plain; markdown-shaped text renders with native layout.

Architecture

Raw message textOriginal markdown remains source of truth for copy and restore.
Fast detectorPlain text skips the renderer; markdown markers enter Rendered Markdown.
markdown-coreProduces app-owned blocks, inlines, code spans, diff lines, and diagnostics.
Native UISwiftUI and Compose render the same conceptual blocks using design tokens.
