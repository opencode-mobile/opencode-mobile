Highlighter: opencode Web vs Mobile

Layer-by-layer comparison of markdown code-block syntax highlighting. opencode web uses Shiki as the authoritative engine; opencode mobile bundles Shiki-derived TextMate grammars and runs a custom native tokenizer that approximates web output.

Oracle tests use opencode-semantic-golden: Shiki forced into the same 18 CodeTokenRole buckets mobile uses. Mobile compresses Shiki leaf scopes by roughly 2×–6× per fixture (3–55 scopes → 2–10 roles). See shiki-visual-parity-paths-plan.html.

Where divergence concentrates

Layers 2–4 (detection, grammars, regex) are aligned with web. The real gap is layer 5: the native tokenizer is an incomplete reimplementation of vscode-textmate. That leaks upward as layer 6 fidelity loss and layer 7 per-language fixups. Layers 1, 9, and 10 are intentional product differences, not defects.
