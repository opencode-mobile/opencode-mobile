# Contributing

Thanks for helping with OpenCode Mobile, the unofficial native iOS and Android
client for [opencode](https://github.com/sst/opencode).

## Issues

Bug reports and feature ideas are welcome as
[GitHub issues](https://github.com/opencode-mobile/opencode-mobile/issues).
For a bug, include the app platform and version, the opencode server version,
what you did, and what you expected. Never paste server passwords or
connection URLs you would not share publicly.

Report security problems privately; see [SECURITY.md](SECURITY.md).

## Pull requests

1. For anything larger than a small fix, open an issue first so we can agree
   on the approach.
2. Keep iOS and Android aligned. A shared product behavior lands on both apps,
   or the issue records the temporary gap.
3. Follow [AGENTS.md](AGENTS.md) for architecture, design-system, and API
   rules, and run the local checks from the [README](README.md).
4. Sign the Contributor License Agreement (below) on your first pull request.

Pull requests from forks do not run the self-hosted CI. A maintainer runs the
checks before merging.
